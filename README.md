# 🎬 Video Website

This repository contains a simple static video website built with HTML. It showcases a video player with a thumbnail preview, making it ideal for learning basic web development and multimedia integration.

---

## 📁 Project Structure

- `index.html` – Main HTML file containing the video player setup.
- `video1.mp4` – Sample video file embedded in the webpage.
- `thumbnail1.jpg` – Thumbnail image displayed before the video plays.
- `.vscode/` – Optional folder for editor-specific settings (can be ignored or customized).

---

## 🚀 Features

- Clean and minimal HTML layout.
- Embedded video player with a custom thumbnail.
- Lightweight and fast-loading—no external libraries or frameworks.

---

## 🛠 How to Run

1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Click the play button to watch the embedded video.

---

## 📌 Use Cases

- Practice project for HTML5 video embedding.
- Starting point for building a personal video portfolio or media showcase.
- Educational resource for learning basic multimedia handling in web development.
